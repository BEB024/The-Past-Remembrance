# The Past Remembrance
An exciting virtual reality escape room game made in Unity 6.3. Created by Ibrahim Labib.

Story:
A family, once of five, is no more. Their estate fell into ruin in a land far from civilization's reach. You, my dear player, are the "The Relative", the only proof that this once great family existed. What exists inside the abandoned mansion? That's for you to discover and find out.

Description
This project is a VR escape game set inside a spaceship. The player is stranded in space and must interact with the environment, objects, and tools to progress.

The game is built using Unity and the XR Interaction Toolkit, focusing on immersive, physics-based interaction.

Game Mechanics

Hand Interaction

The player interacts using VR hands
Grip is used to grab objects
Trigger is used for actions such as shooting
Hands are hidden when holding objects to improve visuals

Object Interaction

Objects can be picked up, moved, and thrown
Uses realistic physics for movement and collision
Objects keep their natural position when grabbed

Object Disposal

The player collects items such as meteor fragments
Items must be thrown into a trash container
When placed correctly:
The object disappears
The action is completed

Vortex Effect

The trash container has a vortex visual effect
Provides feedback when objects are disposed

Pistol System

The player can pick up a sci-fi pistol
Pressing the trigger activates shooting
Used to interact with specific objects

Breakable Objects

Some objects can be destroyed using the pistol
When destroyed:
They break into smaller pieces
The pieces remain interactive

Timed Interaction

Some objects require continuous shooting to break
Prevents instant actions and adds challenge

Movement

Continuous Movement

Controlled using joystick input
Movement follows the direction the player is looking

Teleportation

Optional movement system
Allows quick repositioning in the environment

Environment

The game takes place in a sci-fi spaceship
Includes rooms, corridors, and interactive props
Lighting and effects improve immersion

Gameplay Flow

Explore the environment
Interact with objects
Dispose of items in the trash
Use the pistol to break objects
Continue progressing through interactions
